# 📈 Stock Market Portfolio Analyzer

## 📌 Project Overview

The Stock Market Portfolio Analyzer is a Python-based application that analyzes stock portfolio data from a CSV file.

## 🚀 Features

- Read stock price data from CSV
- Calculate investment value
- Calculate current portfolio value
- Calculate Profit/Loss
- Calculate stock-wise return percentage
- Identify best-performing stock
- Identify worst-performing stock
- Calculate overall portfolio return
- Generate Portfolio Growth Chart
- Generate Sector-wise Investment Chart
- Generate Daily Return Analysis
- Predict next-day trend using Moving Average
- Export portfolio analysis report to CSV
- Interactive Streamlit dashboard

## 🛠️ Technologies Used

- Python
- Pandas
- Matplotlib
- Streamlit
